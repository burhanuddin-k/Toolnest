# ToolNest — Free Online Tools

A responsive, static tools website with six utilities:

- Image compressor (JPEG export)
- Image resizer (PNG export)
- QR code generator (third-party QRServer API)
- Word counter
- Age calculator
- Secure password generator

## Run locally

Open `index.html` in a browser, or run `python -m http.server 5500` and visit http://localhost:5500.

## Deploy on Cloudflare Pages

Connect this repository in Cloudflare Workers & Pages, choose **no framework**, leave the build command blank and use `.` as output directory.

## Before launch

- Replace the contact-page placeholder with a working support address.
- Verify functionality on mobile and desktop.
- Review privacy policy before adding analytics or advertising.
- QR text is sent to an external service; never use sensitive data.
- Search traffic and AdSense approval are not guaranteed.

No Node.js or paid server required.
